ABOUT THE PROJECT

Smarter insights for
better travel planning.

SkyFare is a machine learning airfare estimation system built with FastAPI and Scikit-learn. It extracts and transforms journey parameters through a specialized ColumnTransformer pipeline into a Random Forest Regressor to provide instant price estimates with variance bounds.
